## Report contract (max 20 lines)

- Line 1: `STATUS: done | blocked | partial`
- Files changed: one line per file
- Gates you ran and the result line only (e.g. `Tests 26 passed (26)`), or `not run: <reason>`
- For a review: `Verdict: approve | changes`, then at most 8 findings, one line each: `Severity path:line problem -> fix`
- Exceptions / open questions: one line each
No restating the brief, no file tours, no line-range lists.
